## Regras

- nunca commitar credenciais;
- usar `.env.example` quando necessário;
- documentar pré-requisitos;
- incluir comandos de execução;
- informar como destruir/parar recursos criados;
- evitar custos cloud desnecessários;
- manter exemplos independentes de ambientes corporativos reais.
