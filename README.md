# Formacao DevOps

Repositório de estudos com resumos objetivos, visão prática e materiais de apoio sobre cultura DevOps.

## Visão Geral

Esta formação foi organizada para funcionar como uma trilha progressiva:

1. Entender a base cultural do DevOps
2. Conhecer frameworks de adoção e evolução
3. Traduzir a teoria em ações práticas no time

O foco aqui não é só decorar conceitos, mas criar material que ajude em revisão, entrevistas, estudos e aplicação no trabalho.

## Trilha de Estudos

| Módulo | Tema | Objetivo |
|---|---|---|
| [Módulo 01](./modulo-01-cultura-devops.md) | Cultura DevOps | Entender colaboração, automação, feedback e responsabilidade compartilhada |
| [Módulo 02](./modulo-02-calms-e-as-tres-maneiras.md) | CALMS e as Três Maneiras | Mapear maturidade DevOps e evolução prática da cultura |

## Como Usar

- Leia os módulos em ordem
- Use os resumos visuais para revisão rápida
- Evolua os arquivos continuamente conforme novos aprendizados surgirem

## Para Quem Este Material Serve

- Pessoas iniciando em DevOps
- Desenvolvedores que querem ampliar visão de operações
- Profissionais de infraestrutura que querem fortalecer colaboração com times de desenvolvimento
- Times que querem documentar melhor sua jornada de maturidade DevOps
